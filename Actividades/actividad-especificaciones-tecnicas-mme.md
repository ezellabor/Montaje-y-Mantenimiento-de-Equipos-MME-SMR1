**Módulo:** MME · 1º SMR

## 1. Objetivos de la actividad

- Identificar las características técnicas principales de un equipo informático (procesador, placa base, memoria RAM, almacenamiento, tarjeta gráfica, BIOS/UEFI).
- Utilizar herramientas propias de Windows 11 y herramientas de terceros para recoger esa información.
- Comparar el nivel de detalle y la fiabilidad de la información que aporta cada herramienta.

## 2. Resultado de aprendizaje relacionado

El alumno identifica las características técnicas de los componentes de un equipo informático, utilizando tanto herramientas del propio sistema operativo como software especializado de diagnóstico.

## 3. Herramientas a utilizar

**Del propio Windows 11** (elige 2):
- **Configuración → Sistema → Acerca de**
- **Información del sistema** (ejecutar `msinfo32`)
- *(alternativa válida: Administrador de tareas → pestaña Rendimiento)*

**De terceros** (las dos):
- **CPU-Z** — información detallada de procesador, placa base y memoria.
- **HWiNFO** — informe completo de todos los componentes del equipo, incluidos sensores y temperaturas.

> Usa las versiones portables (sin instalación) de CPU-Z y HWiNFO si el equipo del aula no permite instalar software.

## 4. Desarrollo de la actividad

1. Abre **Configuración → Sistema → Acerca de** y anota los datos que encuentres sobre el procesador, la memoria RAM instalada y el tipo de sistema.
2. Abre **Información del sistema** (`msinfo32`) y busca los mismos datos, junto con el modelo de placa base y la versión de BIOS/UEFI.
3. Ejecuta **CPU-Z** y recorre sus pestañas (CPU, Mainboard, Memory, SPD) anotando los mismos datos.
4. Ejecuta **HWiNFO** (modo resumen o informe completo) y anota los mismos datos, incluida la temperatura del procesador si la muestra.
5. Rellena la tabla comparativa del apartado siguiente con lo que haya mostrado cada herramienta.
6. Responde a las preguntas de comparativa y conclusión final.
